# Loom — Система оперативного планирования производства

Десктопное приложение для управления производственными заказами, загрузкой станков и визуализации расписания (диаграмма Ганта).

## Стек технологий
- Язык: Python 3.11
- Интерфейс: PyQt5
- СУБД: PostgreSQL

## Быстрый запуск
1. Склонировать репозиторий:
   git clone https://github.com/1nkasator/loom.git
2. Создать и активировать виртуальное окружение:
   python -m venv .venv
   source .venv/Scripts/activate
3. Установить зависимости:
   pip install -r requirements.txt
4. Запустить приложение:
   python main.py
